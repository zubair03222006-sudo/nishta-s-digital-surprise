# Nishta's Digital Surprise

Build a beautiful, highly interactive birthday surprise website for a girl named Nishta.

The website should feel like a personalized digital birthday gift + meme museum + cute interactive experience, not like a generic birthday template.

🎨 OVERALL VIBE

Theme:

Cute + funny + slightly chaotic Gen-Z friendship energy

Romantic-looking aesthetics WITHOUT making it overly romantic

Premium, polished, modern UI

Main colors: deep red, soft pink, cream/white, subtle black

Use elegant typography mixed with playful handwritten typography

Lots of hearts ❤️, sparkles ✨, stars ⭐ and birthday elements

Smooth animations everywhere, but don't make the site laggy

Mobile-first because the website will primarily be opened on a phone

Use:

Glassmorphism cards

Soft gradients

Subtle glow effects

Floating hearts

Confetti

Smooth page transitions

Micro-interactions

Hover/tap animations

Scroll-triggered animations

Use a font similar to Dancing Script / Great Vibes for special headings and a clean modern sans-serif for body text.
